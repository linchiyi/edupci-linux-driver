# Demo image source

These five PNGs were rendered from the fresh runtime capture in
`evidence/public_demo_output.txt`. The renderer preserves every displayed log
line verbatim and only adds a dark terminal-style frame and syntax coloring.
Sections 01–04 are crops of the captured output; 05 contains the full demo.
Regenerate them with `python3 scripts/render_demo_assets.py`.
